## 📻 Meu Player de Rádio
Este é o meu projeto principal atual. Uma aplicação web para ouvir estações de rádio online em tempo real.

### 🌟 Funcionalidades
- **Streaming ao vivo**: Áudio de alta qualidade sem interrupções.
- **Busca**: Encontre estações por nome, gênero ou país.
- **Favoritos**: Salve suas rádios preferidas em uma lista personalizada.
- **Modo Escuro**: Interface adaptável para qualquer momento do dia.

### 🛠️ Tecnologias Utilizadas
- **Frontend**: HTML5, CSS3, JavaScript (ou React / Vue)
- **API de Rádio**: variadas / api_config.js
- **Hospedagem**: GitHub Pages / Vercel

---

### 🚀 Como rodar o projeto localmente

1. Clone o repositório:
```bash
git clone https://github.com
```

2. Entre na pasta do projeto:
```bash
cd seu-player-de-radio
```

3. Abra o arquivo `index.html` no seu navegador ou rode o comando de inicialização:
```bash
npm start
```
